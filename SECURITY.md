# Security Policy

## The Only Vulnerability

The only vulnerability in this repository is the heart that turns away after being shown the truth (3:8).

## Reporting a Vulnerability

If you find an error in the Quranic text or translation used here:
1. Open an issue
2. The standard is the Mushaf al-Madinah an-Nabawiyyah

## Responsible Disclosure

This repository contains no code. It contains a covenant.
The only exploit that matters is the one that makes you forget your Creator (59:19).
